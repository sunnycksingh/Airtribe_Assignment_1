JVM Understanding

1. What is JDK, JRE, JVM?

## JVM (Java Virtual Machine)
- The engine that **executes** Java bytecode
- Provides platform independence — same bytecode runs on Windows, Mac, Linux
- Handles memory management, garbage collection, security

## JDK (Java Development Kit)
- Everything you need to **develop** Java applications
- Includes: `javac` (compiler), `javadoc`, `jdb` (debugger), `jar`, and more
- Contains the JRE + development tools

## JRE (Java Runtime Environment)
- Everything needed to **run** Java applications
- Includes: JVM + core libraries (`java.lang`, `java.util`, etc.)
- No compiler — you can only run, not build

2. What is bytecode ?
- An **intermediate representation** of your Java source code
- Generated by the Java compiler (`javac`)
- **Platform-independent** — the same `.class` file runs on any OS
- It is NOT human-readable — it's a set of instructions for the JVM


3. What does “write once, run anywhere” mean?

- “Write once, run anywhere” means you can write your program one time and run it on different systems (like Windows, Mac, Linux) without changing the code.
- It saves time and effort because you don’t have to rewrite your program for every platform—just write it once and it works everywhere (as long as the system supports it, like with Java and JVM).
